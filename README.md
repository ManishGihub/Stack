# 📚 Stack Implementation in Java

A collection of **Stack** implementations and operations in **Java**. This repository demonstrates different ways to implement a stack and solve common stack-related problems using Java.

---

## 🚀 Topics Covered

* ✅ Stack using Java Collections Framework
* ✅ Stack using ArrayList
* ✅ Stack using Linked List
* ✅ Push an element at the bottom of a stack (Recursion)

---

```text
stack/

└── README.md
```

---

## 📌 Programs Included

### 1. Stack Using Java Collections Framework

**File:** `StackUsingCollection.java`

Uses Java's built-in `Stack` class to perform basic stack operations.

**Operations**

* Push
* Peek
* Pop

**Sample Output**

```text
4
3
2
1
```

---

### 2. Stack Using ArrayList

**File:** `StackUsingArrayList.java`

Implements a stack from scratch using an `ArrayList`.

**Operations**

* Push
* Pop
* Peek
* IsEmpty

**Sample Output**

```text
5
4
3
2
1
```

---

### 3. Stack Using Linked List

**File:** `StackUsingLinkedList.java`

Implements a stack using a singly linked list.

**Operations**

* Push
* Pop
* Peek
* IsEmpty

**Sample Output**

```text
5
4
3
2
1
```

---

### 4. Push Element at the Bottom of Stack

**File:** `PushAtLast.java`

Demonstrates how to insert an element at the bottom of a stack using recursion without using any additional data structure.

**Sample Output**

```text
3
2
1
4
```
